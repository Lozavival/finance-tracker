# External Interfaces Map

This document enumerates all external interfaces used or exposed by the Finance Tracker application, including environment variables, file storage, HTTP endpoints, desktop IPC communication channels, and browser local storage.

## Legend

- **Type**: The technology used for the interface (Env Var | File IO | HTTP | IPC | Storage)
- **Direction**: Whether data flows in (Inbound), out (Outbound), or both ways (Bidirectional)
- **Identifier / Path**: Service name, endpoint, file path, channel, or variable
- **Payload in**: What data the app receives
- **Payload out**: What data the app sends
- **Errors**: How errors are handled (log, retry, swallow, rethrow, fallback)
- **Location**: Where in the code the interface is used
- **Purpose**: The functional purpose of the interface
